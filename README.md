# SIGNTUNING website

Website for SIGNTUNING, auto styling specialist in Montagne Blanche, Mauritius: window tint, car wraps, stickers and number plates.

Live: https://webluxe.github.io/SignTuning-Website/

- Plain HTML, CSS and JavaScript. No build step.
- Business details (phone, WhatsApp, area, TikTok numbers) live in `config.js`.
- Photos live in `img/`. Sample photos are marked on the site until they are swapped for the shop's own work (set `demoPhotos: false` in `config.js` to hide the notes).
